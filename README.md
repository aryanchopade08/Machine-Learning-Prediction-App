# Machine Learning Prediction App
A Streamlit-based Machine Learning Prediction App built using Python and Scikit-learn.

## Features
- Classification Prediction
- Regression Prediction
- Interactive Streamlit Interface
- Pre-trained ML Models (.pkl)

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- Joblib
- Pandas
- NumPy

## Run the Project

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```
